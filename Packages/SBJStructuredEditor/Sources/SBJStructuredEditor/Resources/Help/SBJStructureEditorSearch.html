Finding fields and issues

Enter text in the search field to find matching field names or content.

Use UI_changed\ to show only values that have changed since the editor opened, and UI_empty\ to show only values with no content. These filters can be combined with each other and with text search.

Structure report

Select UI_showDefinitionReport\ to open the Data Definition Report for the current structure.

Issues

The editor checks for issues automatically. When issues are present, UI_issues\ appears to the right of the search controls. Select it to check again and open the issue list. The button is hidden when no issues are currently reported.

In the issue list, select UI_navigateToProperty\ for an issue to close the issue list, open any collapsed groups containing that property, and scroll the editor directly to it.
