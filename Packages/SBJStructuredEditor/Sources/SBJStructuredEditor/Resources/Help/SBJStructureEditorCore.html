Using structured editors

Open a group to see its fields, then change values directly. Changes appear as you work.

Value state

  • UI_changed\ marks a value changed since the editor opened.
  • UI_empty\ indicates a field with no content.

Optional values

An optional value can be unset rather than empty.

  • UI_setOptional\ creates and sets a value so it can be edited.
  • UI_clearOptional\ clears the value and returns the field to its unset state.

Field information

  • UI_information\ opens a description of the field and the value to enter.

Opening groups

  • UI_disclosureClosed\ opens a collapsed group.
  • UI_disclosureOpened\ closes an expanded group.

Lists and collections

  • UI_add\ adds an item.
  • UI_remove\ removes an item.
  • UI_moveUp\ / UI_moveDown\ move an item one position.
  • UI_moveToFirst\ / UI_moveToLast\ move an item to the beginning or end.
