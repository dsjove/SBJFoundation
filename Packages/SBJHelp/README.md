# SBJHelp

Reusable SwiftUI Help presentation and template rendering. The package depends on SBJFileResources and SBJLocalization; it does not depend on SBJFoundation.

Callers provide their own `SBJBundledContentReference` assets and application-specific template substitutions via `SBJHelpConfiguration`. HTML files and feature-specific documentation remain with their owning applications/packages.

See [Documentation/Architecture.md](Documentation/Architecture.md).
