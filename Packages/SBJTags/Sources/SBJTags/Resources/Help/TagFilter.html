Tag Filter

Choose which media and associated actor castings appear in the lists. Edits take effect immediately and are saved for this library.

Starting set

Begin with all — Include: Begin with every item. Exclude: Begin with no items.

Rules

UI_add\ Select Add Rule to add a tag. Choose its name from the menu, then select Include or Exclude.

Rules are evaluated from top to bottom. A matching Include rule adds an item; a matching Exclude rule removes it. Later matching rules override earlier ones.

UI_remove\ Remove an individual rule. Clear removes all tag rules without changing the starting set.

Missing tags: A missing or deleted tag is shown in red. It cannot match media until you choose an available tag; the rule is retained so you can repair it.

Done: Close the editor. There is no Apply step, because every change is live. To reset the filter completely, use the Reset Tag Filter button in Jove's Movies.
