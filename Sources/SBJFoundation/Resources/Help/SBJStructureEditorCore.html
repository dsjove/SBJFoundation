Using structured editors

Open a group to see its fields, then change values directly. Changes appear as you work.

Value state

UI_changed\ marks a value that differs from the value present when the editor opened. UI_empty\ indicates a field with no content.

Optional values

An optional value can be unset rather than empty. UI_setOptional\ creates and sets the value so it can be edited. UI_clearOptional\ clears it and returns the field to its unset state.

Field information

UI_information\ beside a field opens a short explanation of that field and the kind of value to enter.

Opening groups

UI_disclosureClosed\ opens a collapsed group. UI_disclosureOpened\ closes an expanded group.

Lists and collections

UI_add\ adds an item. UI_remove\ removes an item. When ordering is available, UI_moveUp\ and UI_moveDown\ move an item one position, while UI_moveToFirst\ and UI_moveToLast\ move it to the beginning or end of the list.
