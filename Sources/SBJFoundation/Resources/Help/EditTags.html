TITLE

Tags help you organize your items by themes or any other grouping.

Managing tags

  • UI_add\ Select Add Tag to create a tag.
  • Search: Filter tags using the search field.
  • Rename: Select a tag's name to edit it.
  • Color: Select the color swatch to change a tag’s color.
  • UI_checked\ Apply the tag to the current item.
  • UI_notPrimaryTag\ Set the tag as the item's primary tag. UI_primaryTag\ identifies the primary tag.
  • Delete: Swipe to remove tags you no longer need.

Tip: Tags make searching for and grouping your items easier.
