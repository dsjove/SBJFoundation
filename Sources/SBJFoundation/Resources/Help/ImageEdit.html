TITLE

Use the image editor to crop, position, rotate, mirror, and mark up an image before saving it.

Crop and position

  • UI_crop\ Choose a crop shape. A checkmark marks the current crop.
  • Swap Width & Height: Swap the width and height of a crop ratio, such as 4:3 to 3:4.
  • Drag the image to reposition it inside an active crop. Pinch to zoom.
  • Double-tap the image or select UI_resetPanZoom\ Reset Pan & Zoom to restore its position and magnification.
  • For a freeform crop, drag the lower-right handle to change its proportions.

Rotate and mirror

  • UI_rotateLeft\ rotates the image 90 degrees counterclockwise.
  • UI_mirrorHorizontal\ mirrors the image horizontally. If vertical mirroring is available, UI_mirrorVertical\ mirrors it vertically.
  • UI_straighten\ opens fine straightening. The displayed angle is the image's full rotation, including quarter turns.
  • In the straighten control, UI_rotateLeft\ and UI_rotateRight\ provide quarter turns and UI_resetStraighten\ restores the fine straighten value.

Markup and sharing

  • UI_markup\ shows drawing tools when markup is enabled. UI_hideMarkup\ hides them.
  • UI_eraseMarkup\ clears markup, while UI_undoMarkup\ and UI_redoMarkup\ step through drawing changes.
  • UI_share\ shares the currently edited image when sharing is enabled.

Done is available only when the image has an effective edit.
